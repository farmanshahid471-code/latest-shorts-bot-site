Latest Shorts Bot

Latest Shorts Bot is a desktop content-management application that helps its operator create and publish short-form videos to authorized social media accounts.

How it works

The application processes videos selected by the operator, prepares titles and hashtags, and publishes finished videos to accounts that the operator has explicitly connected.

TikTok access is authorized through TikTok's official OAuth and Content Posting APIs. The application does not request or collect TikTok passwords.

User control

Users choose which accounts are connected and can disable TikTok posting from the application's control panel. Access can also be revoked through the user's TikTok account settings.

Latest Shorts Bot is an independent application and is not affiliated with, endorsed by, or operated by TikTok.
